# Quick Start Guide - Admin Candidate Management

## 🚀 Getting Started in 5 Minutes

### Step 1: Access Admin Panel
```bash
cd admin
npm start
```
Navigate to: `http://localhost:8081`

### Step 2: Login as Admin
Use your admin credentials to login.

### Step 3: Find a Candidate
1. Click "Candidate Search" in sidebar
2. Search for a candidate
3. Click on candidate card to view details

---

## 🎯 Quick Actions

### Manage Labels (30 seconds)
1. Open candidate details
2. Click "Manage Labels"
3. Select labels (Premium, Starred, Featured, etc.)
4. Click "Save Labels"
5. ✅ Done! Labels appear immediately

### Edit Candidate Profile (2 minutes)
1. Open candidate details
2. Click "Edit Profile"
3. Switch between tabs: Personal | Professional | Preferences
4. Edit any field
5. Click "Save Changes"
6. ✅ Done! Changes saved

### Upload Profile Photo (1 minute)
1. Open "Edit Profile"
2. Click on profile image
3. Select image (JPEG/PNG, max 5MB)
4. ✅ Done! Photo uploaded automatically

### Upload Resume (1 minute)
1. Open "Edit Profile"
2. Click "Upload Resume"
3. Select document (PDF/DOC/DOCX, max 10MB)
4. ✅ Done! Resume uploaded

### Login as User (30 seconds)
1. Open "Edit Profile"
2. Click "Login as User" (green button)
3. Confirm action
4. ✅ Done! You're now logged in as that user

## 🐛 Common Issues & Solutions

### Issue: Can't upload photo
**Solution:** Check file size (max 5MB) and format (JPEG/PNG)

### Issue: Can't save changes
**Solution:** Fill all required fields, check internet connection

### Issue: Labels not showing
**Solution:** Refresh page, clear cache

### Issue: Can't login as user
**Solution:** Verify admin permissions, check user is active
