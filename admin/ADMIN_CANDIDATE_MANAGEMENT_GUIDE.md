# Admin Candidate Management - User Guide

## Overview

The Admin Candidate Management system provides comprehensive tools for administrators to manage candidate profiles, including editing details, uploading documents, managing labels, and even logging in as users for support purposes.

## Features

### 1. **View Candidate Details**
- Navigate to: Admin Dashboard → Candidate Search → Select Candidate
- View complete candidate profile including:
  - Personal information
  - Professional details
  - Education history
  - Job preferences
  - Profile status and completion
  - Assigned labels

### 2. **Edit Candidate Profile**
From the Candidate Details screen, click the "Edit Profile" button to access the comprehensive editing interface.

#### Personal Information Tab
Edit the following fields:
- Full Name
- Email Address
- Phone Number
- WhatsApp Number
- Gender
- Date of Birth
- Current City
- Pincode
- Category
- Marital Status

#### Professional Information Tab
Edit the following fields:
- Current Job Title
- Current Company
- Total Experience (years)
- Current Salary
- Industry
- Department
- Key Skills (multiple)
- Preferred Languages (multiple)
- English Fluency Level
- Company Type

#### Preferences Tab
Edit the following fields:
- Job Type Preference
- Employment Type
- Work Mode (WFH/WFO/Hybrid)
- Expected Salary
- Notice Period
- Willing to Relocate
- Preferred Locations (multiple)

### 3. **Upload Profile Photo**
1. Go to Edit Candidate screen
2. Click on the profile image placeholder
3. Select an image from your device
4. Supported formats: JPEG, PNG, GIF
- Maximum size: 5MB
5. Image will be automatically uploaded and displayed

### 4. **Upload Resume**
1. Go to Edit Candidate screen
2. Click "Upload Resume" button
3. Select a document from your device
4. Supported formats: PDF, DOC, DOCX
   - Maximum size: 10MB
5. Resume will be uploaded and linked to the candidate profile

### 5. **Manage Candidate Labels**
Labels help categorize and prioritize candidates.

**Available Labels:**
- 🌟 **Premium Candidate** (Gold) - High-value candidates
- ⭐ **Starred Candidate** (Orange) - Marked for follow-up
- 🎀 **Featured Candidate** (Purple) - Showcase candidates
- 🔍 **Actively Job Searching** (Green) - Currently looking
- 🚨 **Urgent Candidate** (Red) - Requires immediate attention
- 📈 **Profile Booster** (Blue) - Enhanced visibility

**How to Manage Labels:**
1. Go to Candidate Details or Edit Candidate screen
2. Click "Manage Labels" button
3. Select/deselect labels as needed
4. Click "Save Labels"
5. Labels will be visible on:
   - Candidate details page
   - Candidate search results
   - User's own profile (they can see their labels)

### 6. **Login as User**
This feature allows admins to access the platform as a specific user for support and troubleshooting.

**How to Use:**
1. Go to Edit Candidate screen
2. Click "Login as User" button (green button)
3. Confirm the action in the popup
4. You will be logged out from admin panel
5. You will be logged in as the selected user
6. Navigate the platform as that user
7. To return to admin, logout and login with admin credentials

**Important Notes:**
- This action is logged for security and audit purposes
- Use this feature responsibly and only when necessary
- The user may be notified of admin access (depending on settings)
- You will need to logout and re-login as admin to return

### 7. **Save Changes**
After making any edits:
1. Review all changes carefully
2. Click "Save Changes" button at the bottom
3. Wait for confirmation message
4. Changes will be immediately reflected in the system

## Workflow Examples

### Example 1: Complete Profile Update
1. Search for candidate
2. Click on candidate to view details
3. Click "Edit Profile"
4. Upload profile photo
5. Upload resume
6. Update personal information
7. Update professional details
8. Add/update labels
9. Save changes
10. Verify updates in candidate details

### Example 2: Quick Label Update
1. Search for candidate
2. Click on candidate to view details
3. Click "Manage Labels"
4. Select "Premium Candidate" and "Actively Job Searching"
5. Click "Save Labels"
6. Labels appear immediately on profile

### Example 3: Support Session
1. User reports an issue
2. Admin searches for user
3. Click "Edit Profile"
4. Click "Login as User"
5. Confirm action
6. Reproduce and fix the issue
7. Logout
8. Login back as admin
9. Document the resolution

## Best Practices

### Data Management
- ✅ Always verify candidate identity before making changes
- ✅ Double-check email and phone numbers
- ✅ Keep professional information up-to-date
- ✅ Use labels consistently across all candidates
- ✅ Upload high-quality profile photos
- ✅ Ensure resumes are current and complete

### Label Usage
- **Premium Candidate**: Top-tier candidates with exceptional profiles
- **Starred Candidate**: Candidates you want to follow up with
- **Featured Candidate**: Showcase on homepage or special sections
- **Actively Job Searching**: Currently in job market
- **Urgent Candidate**: Needs immediate placement
- **Profile Booster**: Give extra visibility in search results

### Security
- ⚠️ Use "Login as User" only when necessary
- ⚠️ Never share admin credentials
- ⚠️ Log out after completing admin tasks
- ⚠️ Verify user identity before making sensitive changes
- ⚠️ Keep audit logs for compliance

### File Uploads
- 📸 Profile photos should be professional headshots
- 📸 Recommended size: 500x500px
- 📄 Resumes should be in PDF format for best compatibility
- 📄 Ensure resumes are virus-free
- 📄 File names should be descriptive

## Troubleshooting

### Issue: Cannot upload profile photo
**Solution:**
- Check file size (max 5MB)
- Verify file format (JPEG, PNG, GIF only)
- Ensure stable internet connection
- Try a different image

### Issue: Cannot upload resume
**Solution:**
- Check file size (max 10MB)
- Verify file format (PDF, DOC, DOCX only)
- Ensure file is not corrupted
- Try re-saving the document

### Issue: Changes not saving
**Solution:**
- Check internet connection
- Verify all required fields are filled
- Check for validation errors
- Try refreshing the page and re-entering data

### Issue: Cannot login as user
**Solution:**
- Verify you have admin permissions
- Check if user account is active
- Ensure user is not already logged in elsewhere
- Contact system administrator

### Issue: Labels not appearing
**Solution:**
- Refresh the page
- Clear browser cache
- Verify labels were saved successfully
- Check if labels are enabled in settings
